# Student Hub

A simple study site for NCEA students. This project is organized to keep files clean and easy to navigate as the project grows.

### File Structure
* `index.html`: The main landing page with navigation and quick-links.
* `resources.html`: The layout for viewing subjects and study standards.
* `group-finder.html`: The page for finding and joining study groups.
* `css/`: Contains `style.css` for all visual design and layout settings.
* `js/`: Contains `main.js` for all interactive features like timers or forms.
* `assets/`: Folder for any images or extra files.

### How to use
1. Make sure you have the files organized as shown in the structure above.
2. Open `index.html` in your web browser to view the site.
3. Use the links in the top navigation bar to move between pages.
